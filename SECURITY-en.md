<h1>Security Policy</h1>

<h2>Repository Purpose</h2>
<p>This repository is only for public distribution and archiving of materials, provided via GitHub Releases attachments. </p>

<h2>When to Report</h2>
<p>If you find any of the following, please contact me:</p>
<ul>
  <li>A downloaded file contains malicious content, viruses, or appears tampered with</li>
  <li>A file infringes copyright, privacy, or other lawful rights/interests</li>
  <li>The repository contains leaked keys, tokens, passwords, or personal sensitive information</li>
  <li>The repository contains pornographic, vulgar, or other content violating laws of the People's Republic of China</li>
</ul>
<p>Do not report the above via public Issues—especially for infringement or sensitive information, as public discussion may cause secondary spread.</p>

<h2>Contact</h2>
<ul>
  <li>Use “Report a vulnerability” on this repository’s Security page</li>
</ul>
<p>When reporting, include: filename, Release version/tag, issue description, and supporting evidence if any.</p>

<h2>Response Time</h2>
<p>I will confirm as soon as possible. Malicious files or personal information leaks are prioritized; related attachments may be removed or replaced if necessary.</p>

<h2>For Downloaders</h2>
<ul>
  <li>All attachments are publicly distributed and downloadable by anyone. Do not upload content you do not want public.</li>
  <li>Verify file safety after downloading.</li>
  <li>This repository does not guarantee the content of third-party source files.</li>
